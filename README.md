# Shahab Ahmed — React Resume Template

Production-ready A4 resume template built with React + Vite and plain CSS.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## PDF export

Open the app in Chrome/Edge → Print → Paper size **A4** → Margins **None** → enable **Background graphics** → Save as PDF.

The template contains dedicated print styles, fixed A4 pages, page breaks, and local image assets.

## Customize

All resume content is in `src/main.jsx` inside the `resume` object. Styling is in `src/styles.css`.
